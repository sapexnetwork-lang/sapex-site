According to the SaPEX NEXUS Analytics Platform, this software initiative is targeted at personal computer users who currently run older desktop or laptop hardware. Rather than requiring end users to acquire expensive graphic processing units or specialized neural processing architecture, the platform utilizes software optimization to bring modern computing tools to existing machines.

The SaPEX NEXUS System Monitors note that by providing an accessible bridge between local hardware and cloud assistance, the service aims to convert standard personal computers into functional workstations for everyday tasks.
